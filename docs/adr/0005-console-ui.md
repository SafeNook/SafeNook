# 0005. Spectre.Console для консольного UI

- **Статус:** Принято
- **Дата:** 2026-10-21

## Контекст

Нужны красивый вывод (таблицы, панели, цвета, корректные в светлой и тёмной теме), интерактивные prompt'ы с выбором из списка и поиском, и интерактивный режим с автоблокировкой. Команды должны оставаться пригодными для скриптов (`--json`, без TTY).

## Решение

- **Spectre.Console** — вывод и prompt'ы. Разбор аргументов остаётся за **System.CommandLine 2.0**.
- Интерактивный режим строится на Spectre со своим циклом ввода (опрос `Console.KeyAvailable` + таймер), потому что стандартные prompt'ы блокирующие и не дают сделать автоблокировку.
- Весь вывод идёт через `IAnsiConsole`, чтобы тестировать его через `Spectre.Console.Testing`.

## Альтернативы

- **Terminal.Gui v2** — полноценный полноэкранный TUI. Мощнее, но тяжелее и меньше подходит для обычных команд. Остаётся вариантом, если интерактивному режиму понадобится полноэкранный интерфейс.
- **Свой ANSI-вывод** — это и делала прошлая утилита; результат выглядел плохо в тёмных темах.

## Последствия

- Перед этапом 2 проверить совместимость Spectre.Console с trimming/Native AOT (ограничения по рефлексии).
- Уважаем `NO_COLOR` и отсутствие TTY через возможности Spectre по определению терминала.

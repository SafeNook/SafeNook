# 0001. Имя проекта SafeNook, команда `nook`

- **Статус:** Принято
- **Дата:** 2026-10-21

## Контекст

Проект вырос из PasswordGeneratorCLI с командой `pwgen`. Имя `pwgen` занято классической Unix-утилитой во всех основных пакетных менеджерах (apt, Homebrew, AUR), поэтому распространять под ним бинарник невозможно. Новый проект начинается в чистом репозитории под собственной GitHub-организацией.

Требования к имени: уникальное в нише менеджеров паролей и секретов, без созвучия с конкурентами, свободное в GitHub, NuGet и пакетных менеджерах, короткая команда.

## Решение

- Проект и организация: **SafeNook** («надёжный укромный уголок»).
- Команда в терминале: **`nook`**.
- Пакеты в дистрибутивах: `safenook` (AUR: `safenook-bin`), NuGet: префикс `SafeNook.*`, Docker: `ghcr.io/safenook/*`.
- Пути хранения: `safenook` (Linux), `SafeNook` (macOS, Windows); переменные окружения с префиксом `SAFENOOK_`.

## Альтернативы

Проверены 21.10.2026 по GitHub, NuGet, npm, PyPI, App Store и веб-поиску:

| Кандидат | Причина отказа |
|---|---|
| Tumbler | Пакет Xfce `tumbler` во всех дистрибутивах |
| Keyhold | Существующий менеджер учётных данных keyhold.io |
| Sekret | .NET-платформа секретов Sekret с пакетами в NuGet; Go CLI для секретов Kubernetes |
| Keyward | TUI для SSH-ключей с зашифрованным хранилищем (2026) |
| Celare | npm-пакет `celare` — CLI для секретов и переменных окружения |
| Sigilo | 2FA-аутентификатор в App Store |
| Arcave | Приложение-дневник Arcave на iOS/Android, домены заняты |
| KeyCase | Менеджер паролей Keycase в App Store; организация `keycase` на GitHub |
| Keyden | npm-пакет `keyden` — зашифрованное хранилище секретов |
| KeyCrate, Keyloft | Существующие продукты (SDK лицензий, приложение для арендодателей) |
| SafeSave | Свободно, но имя почти описательное и теряется в поиске |

Для команды рассматривались `snook` (обычное английское слово) и `safenook` (длинно печатать).

## Последствия

- `nook` совпадает по имени с линейкой электронных книг Barnes & Noble, но это не бинарник в дистрибутивах. Перед этапом 2 проверить репозитории дистрибутивов; запасной вариант — `snook`.
- До первой публикации нужно занять домен `safenook.dev` и префикс `SafeNook.*` в NuGet.
